📖 Description

Cuts every video of a multi-camera session at once, keeping them synchronized. All cameras are shown side by side in one mosaic window, driven by one shared timeline with three handles: green ▲ Start, red ▲ End and a blue cursor showing the video at that instant.

The timeline is in time (seconds), not frames: webcams often run at different and variable frame rates (e.g. a 1280x720 camera limited by USB bandwidth to ~8 fps next to 30 fps cameras). Each camera maps timeline time to its own frame using the real packet timestamps of the file, so a cut keeps every camera on the same instant, each with its own number of frames.

Each camera has an offset in milliseconds (camera time = timeline time + offset); one arrow click moves it by one frame of that camera. Step it until a sharp event (clap, flash) lines up in every tile.

  • Mosaic view, each tile showing its own frame number and fps; tiles turn green inside Start/End
  • Range timeline: drag Start/End (the mosaic follows the handle) and the cursor; click to jump
  • Common range highlight: where every camera has video is shaded blue; Start/End stay inside it
  • Frame-accurate cut (hardware H.264 when available, CPU libx264 fallback) that keeps each frame's real timestamp
  • Background cutting with Cancel; prints the equivalent ffmpeg command per camera
  • Reproducible output: multicam_cut.toml records times, offsets and frame ranges
  • Remembers the last session (~/.vaila/vaila_config.toml): the folder field comes pre-filled (Enter reloads it) and Browse... opens in the folder that holds your sessions

🚀 Usage

GUI: select Cut Cameras in vailá's Video and Image tools (next to Record Cameras).

  1. Browse... to a session folder (at least 2 videos).
  2. If needed, step each camera's Offset (ms) until a sharp event lines up in every tile.
  3. Drag the green ▲ to the start and the red ▲ to the end (or press i / o at the cursor).
  4. Click Cut all cameras.

Keys (control or mosaic window): Space play/pause · a/d ±1 frame · j/l ±10 frames · i/o Start/End at cursor

Standalone:

uv run python vaila/multicam_cut.py /path/to/session_dir

Output:

<session_dir>/processed_multicam_cut_YYYYMMDD_HHMMSS/
    cam1_trial01_frame_<a>_to_<b>.mp4
    cam2_trial01_frame_<a>_to_<b>.mp4
    multicam_cut.toml

Frame numbers are 1-based, inclusive. All outputs cover the same time span.

🔧 Main Functions

  • discover_session_videos — Session videos in natural camera order
  • read_frame_times / frame_index_at — Real per-frame timestamps and time→frame lookup
  • timeline_bounds / common_range — Timeline math (seconds) with per-camera offsets
  • validate_cut / camera_frame_ranges — Validate a cut and map it to each camera's frames
  • cut_camera — ffmpeg cut keeping real frame timestamps
  • RangeTimeline — Start / cursor / End timeline widget
  • build_cut_report — TOML record of the cut
  • MulticamCutApp — Tkinter control window + cv2 mosaic
  • run_multicam_cut — GUI entry point

⚠️ Known Limitations (v1)

  • Alignment is manual (no automatic clap/flash detection yet).
  • A camera at a much lower frame rate (e.g. ~8 fps) limits timing precision for that view.
  • Output is re-encoded (H.264) for frame accuracy, not stream-copied.
